# Problem Statement
People often need to keep track of their daily money transactions like deposits and withdrawals. Writing them on paper is inconvenient and calculating the balance by hand can cause mistakes. There is a need for a simple program that can record deposits and withdrawals, show the current balance, and display a clear summary of all transactions.

# Scope of the Project
This project is a console-based application that works only while the program is running. It allows the user to add deposits, add withdrawals, view all transactions, view only deposits or only withdrawals, check the account summary, and delete any transaction. All data is stored in a list in memory. No files or external databases are used. The project is limited to basic operations and does not include features like user login, interest calculation, or permanent data storage.

# Target Users
This program is mainly useful for students and beginners who want to practice basic Python programming. It can also be used by anyone who wants a simple tool to temporarily record and check their money transactions without using complicated software.

# High Level Features
- Add a new deposit with amount and note
- Add a new withdrawal with amount and note
- View all recorded transactions
- View account summary (total deposits, total withdrawals and current balance)
- View only deposit transactions
- View only withdrawal transactions
- Delete any transaction using its ID
- Simple menu-driven interface
